# 我的業務資料庫｜檔案索引

## 資料夾結構
| 資料夾 | 內容 | 什麼時候查 |
|---|---|---|
| `01_價格方案/` | 價格表 PDF、價格速查 md | 報價、確認方案含不含某功能 |
| `02_產品模組簡報/` | 官方各模組簡報 | 抽頁、查模組細節 |
| `03_API開發文件/` | API 速查、官方文件存檔 | 客戶問串接、要買哪支 API |
| `04_合作客戶案例/` | 合作客戶名單、案例頁、logo | 放同業案例、陌生開發去重 |
| `05_提案簡報_範本參考/` | 完整提案範本 | 新提案找版型與截圖 |
| `06_提案簡報_客戶專案/` | 一客戶一資料夾 | 追客戶版本、找素材 |
| `_scripts/` | 產生簡報與網頁的腳本 | 改版、重建 |
| `_to_delete/` | 暫存檔 | 定期確認後清掉 |

## 檔案清單
（每個資料夾底下列出檔名與一句說明，新增檔案時補上）

## 命名規則
- 客戶提案：`<客戶> x Omnichat_<主題>_<日期或版本>.pptx`
- 官方模組簡報：`<模組英文名>_<中文說明>.pptx`，去掉「的副本」
- 合作客戶案例頁：`合作客戶頁_<產業組合>.pptx`
- 舊版檔名後面加 `_v1_舊版`
