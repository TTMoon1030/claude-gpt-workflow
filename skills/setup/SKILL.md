# 第一次設定

`<外掛>`＝有 `scripts/` 資料夾的那一層，也就是這份 SKILL.md 所在資料夾的上上一層（從 GitHub 安裝的是 `…/gpt-workflow/<版本>/`）；`<Codex>` 是第 1 步查到的 Codex 完整路徑；`<DB>` 是資料庫位置，預設 `~/Desktop/我的業務資料庫`，第 0 步決定沿用別的資料夾時就用那個。

使用者不熟終端機：所有指令都由你執行，開始前先跟使用者說「接下來我執行指令時會跳出確認，按『允許』就好」。需要使用者動手或做決定時，先用一句話說要做什麼，等回覆再繼續。生圖一律用這台 Mac 的 Codex（ChatGPT 登入）：不要改用 OpenAI API、不要寫呼叫 API 的腳本、不要跟使用者要 API 金鑰。

0. **整理舊版**：執行 `bash "<外掛>/scripts/scan_legacy.sh"`（只讀，不改檔案）。總結是「沒有找到舊版留下的東西」就直接做第 1 步；找到東西就先照 migrate 技能（`<外掛>/skills/migrate/SKILL.md`）處理，處理完再回來做第 1 步。
1. **檢查**：執行 `bash "<外掛>/scripts/doctor.sh" "<DB>"`，照結果處理，處理完再跑一次，直到總結不是「Codex 需要處理」（資料庫還沒建好是正常的，第 2 步會建）：
   - Codex 未找到：請使用者安裝 ChatGPT 桌面版（https://chatgpt.com/download/ ，需要 ChatGPT Plus 以上方案），打開並登入後告訴你。
   - 生圖功能未開啟：執行 `"<Codex>" features enable image_generation`。
   - 未登入：在背景執行 `"<Codex>" login --device-auth`，從輸出找出網址和代碼給使用者（15 分鐘內有效），並說明畫面上「別人給你代碼就取消」的提醒是正常的，因為是使用者自己要登入。這個程序要在背景一直跑到使用者說好；代碼過期就重跑。
2. **建資料庫**：執行 `bash "<外掛>/scripts/build_db.sh" "<DB>"`。它會建立資料夾、README_索引.md 和 CLAUDE.md，已經有的資料夾和檔案不會被覆蓋；第 0 步跑過的話，這裡會顯示「保留原檔」，是正常的。
3. **測試生圖**：在背景執行 `bash "<外掛>/scripts/test_image.sh" "<DB>"`（約 1–2 分鐘），完成後用 Read 打開它最後一行印出的 test.png 給使用者看。失敗時照 check 技能（`<外掛>/skills/check/SKILL.md`）的對照表處理，再測一次。
4. **回報**：用表格列出舊版整理（有做的話）、Codex 位置、登入、資料庫、測試圖，每項是「完成」「需要你處理」或「跳過」（跳過要寫原因）。最後提醒使用者：按 ⌘Q 重開 Claude（讓外掛生效），點左上「＋ 新增」，資料夾選 `<DB>` 那個資料夾開新對話，之後每天都從這裡開始；要圖片時直接說「用 GPT 畫…」。
