# 工作台（hub）

VT Workshop 工作台在 https://vt-ai-workshop.pages.dev/hub/ ，用 LINE 登入。夥伴做好的客戶網頁都貼在廣場，工坊有開發、Demo、會後、成交用的現成指令，動畫庫可以挑動畫。

- 使用者說「打開工作台」：執行 `open https://vt-ai-workshop.pages.dev/hub/`。
- 使用者說「貼到廣場」：確認網頁已經有網址，打開工作台，請使用者按右上角「貼到廣場」並貼上網址，客戶名和分類會自動帶入。
- 外掛要更新：到小鎮入口的「外掛更新站」按「一鍵更新」。
