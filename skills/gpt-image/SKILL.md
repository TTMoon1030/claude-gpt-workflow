# 用 Codex 叫 GPT 生圖

外掛資料夾＝這份 SKILL.md 往上兩層的資料夾，下面寫作 `<外掛>`。

不要改用 OpenAI API、不要寫呼叫 API 的腳本、不要跟使用者要 API 金鑰。這台電腦的 Codex 用的是 ChatGPT 登入。

1. **確認能用**：執行 `bash "<外掛>/scripts/find_codex.sh"` 取得 Codex 路徑，再跑 `"<Codex>" login status`。找不到或沒登入，照 `<外掛>/skills/check/SKILL.md` 處理；使用者說先不登入，就把這張圖暫停，不要改用其他方式。
2. **寫 prompt.txt**：放在輸出資料夾（客戶資料夾裡的 `_素材/gpt/`，沒有客戶資料夾就問使用者要放哪裡）。內容寫清楚：
   - 用途和風格、品牌色碼。
   - 每張的檔名和尺寸：橫式 1536x1024、方形 1024x1024、直式 1024x1536。
   - 「畫面不要有任何文字和 logo」。
   - 人物用扁平插畫、臉部極簡，不要寫實人像（依照過去使用者經驗，寫實人像 AI 感太重）。
   - 要和舊圖風格或人物一致時，寫「以 某某.png 當參考」。
3. **生圖**：在背景執行 `bash "<外掛>/scripts/gen_image.sh" <輸出資料夾> <輸出資料夾>/prompt.txt [參考圖 ...]`。每張大約 1 分鐘，生圖比一般對話更快用完 Codex 額度，不要一次重畫全部。
4. **檢查**：逐張用 Read 打開。不合格的只重畫那一張（另寫一份只有那張的 prompt）。

不要用 GPT 畫：品牌 logo、官方徽章（用官方原圖）、需要正確中文字的畫面（先畫沒有字的底圖，字再用 HTML 或簡報疊上去）。
