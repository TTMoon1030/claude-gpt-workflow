# 從動畫存儲區套用動畫

清單網址：https://claude-workflow-guide.pages.dev/motion/effects.json （教學頁的「動畫存儲區」也是讀這份）。

省 token 的做法：總清單只有每個動畫的編號、名稱、適合講什麼（每個約 150 token）；挑好之後才讀那個動畫的 `detail`（effect.json，約 600 token）。程式和圖檔用 `curl -L` 直接下載（網址會轉址，一定要加 -L），不要讀內容；示範頁 index.html 只有在要整段照搬時才下載。

1. **挑動畫**：用 `curl -sL` 讀總清單。使用者有說編號就用那個；只描述想要的效果，就從 name、summary、useFor 挑最接近的，先跟使用者確認；什麼都沒說就列出清單讓使用者選。
2. **讀用法**：用 `curl -sL` 讀那個動畫的 `detail`，裡面有 `files`、`fileUrls`、`claude`（接進網頁的步驟）。
3. **下載（有快取）**：快取位置是 `我的業務資料庫/_scripts/特效庫/<slug>/`。那裡的 `.updated` 內容等於清單的 `updated`，就直接用；不然把 `fileUrls` 一個個用 `curl -L` 下載（保留 assets/ 這層資料夾），再把 `updated` 寫進 `.updated`。
4. **放進網頁**：把快取複製到網頁資料夾的 `fx/<slug>/`，照 `claude` 欄位的步驟接上。一定要把渠道、入口、標籤、品牌名換成這個客戶的；只用方案做得到的功能，不要寫會員等級或自訂屬性。
5. **確認**：用瀏覽器打開網頁，看動畫有在跑、手機寬度（375px）不會左右捲動、系統開「減少動態效果」時不會壞掉。回報用了哪個動畫、換了哪些內容。

清單抓不到時，跟使用者說動畫存儲區暫時連不上，不要自己從頭寫一個類似的動畫來代替，除非使用者同意。
